### Controls:
- WASD:            Movement
- Left-click:      Attack (hold down for power) / Interact with GUI
- Space:           Roll
- E:               Interact
- ESC:             Pause
- Left Alt (hold): Open Inventory
- M:               Toggle Map

### Debug Hotkeys:
- `:               Toggle Performance Window
- 1:               Fill Inventory
- /:               Toggle Theseus' Collider
- \\:              Toggle Collider Visualizations
- Up Arrow:        Apply Regen Status
- Down Arrow:      Apply Paralyzed Status
- Left Arrow:      Apply Burning Status
- Right Arrow:     Apply Poisoned Status
- Page Up:         Superspeed
- Page Down:       God Mode
- Home:            Teleport to Spawn
- Right Shift:     Teleport to Minotaur's Chamber
- \-:              Zoom out
- +:               Zoom in
- ;:               Toggle Labyrinth Configuration Window (Unfinished!)
