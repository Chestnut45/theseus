### Controls:
WASD:            Movement\
Left-click:      Attack (hold down for power) / Interact with GUI\
E:               Interact\
ESC:             Pause\
Left Alt (hold): Open Inventory\
M:               Toggle Map\
Space:           Roll\
Delete:          Toggle Debug Hotkeys\
`:               Toggle Performance Window\

### Debug Hotkeys:
0:               Toggle Inventory\
9:               Play Intro Cutscene\
1:               Fill Inventory\
;:               Toggle Labyrinth Configuration Window\
/:               Toggle Theseus' Collider\
Up Arrow:        Regenerate\
Down Arrow:      Paralyze\
Left Arrow:      Burn\
Right Arrow:     Poison\
Page Up:         Superspeed\
Page Down:       God Mode\
Page Left:       Teleport to Spawn\
Right Shift:     Teleport to Minotaur's Chamber\
\-:              Zoom out\
+:               Zoom in
